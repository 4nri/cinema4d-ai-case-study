# Кубики, физика и AI

12 слайдов на 8–10 минут о работе над сценой Cinema 4D через MCP.
Обновлённая версия: исходное фото рядом с моделью, крупные кадры, скриншоты Takes и Annotation из Cinema 4D. Текст и заметки вычитаны по humanizer-ru.

## Открыть локально

Откройте `index.html` в браузере. Интернет и установка зависимостей не нужны. Папка `assets` должна лежать рядом с HTML.

## Опубликовать через GitHub Pages

1. Распакуйте архив. Загрузите **его содержимое** в корень репозитория: `index.html`, `style.css`, `deck.js`, папку `assets` и остальные файлы. Сам ZIP загружать не нужно.
2. Откройте **Settings → Pages** в репозитории.
3. В **Build and deployment → Source** выберите **Deploy from a branch**.
4. Выберите **main** и **/ (root)**, нажмите **Save**.
5. Дождитесь публикации. Ссылка появится на той же странице: `https://USERNAME.github.io/REPOSITORY/`.

Все пути относительные: презентация работает и в корне сайта, и в папке репозитория. Сборка, npm, сторонние сервисы и Git LFS не нужны. Пустой `.nojekyll` отключает обработку Jekyll.

Документация GitHub: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Управление

- Стрелки ← →, Page Up / Page Down: слайды.
- Пробел: следующий слайд.
- Home / End: первый / последний слайд.
- F: полный экран.
- P: заметки докладчика в отдельном окне с таймером.
- N: заметки поверх слайда.
- O: содержание.
- Esc: закрыть заметки или содержание.
- На сенсорном экране: свайп влево или вправо.

Горячие клавиши работают и при русской раскладке. Для созвона удобнее показывать окно со слайдами, а заметки держать в отдельном окне. На слайде 6 можно выбирать пары чисел. Все видео запускаются автоматически без звука при открытии слайда и повторяются по кругу. На других слайдах воспроизведение приостанавливается. Фотографии и скриншоты с курсором увеличения можно открыть нажатием; Esc закрывает просмотр.

## Медиа и ограничения

Медиа взяты из рабочего проекта. Схема коллайдера условная. На слайде со слоями Shadows показан alpha-канал, яркость RGB Reflections увеличена в четыре раза для просмотра. Подробности записаны в `sources.json`.

Сохранены 25 fps исходных видео и оговорка о допуске примерно 0,25 мм для T06. Презентация не утверждает, что все броски целиком находятся внутри точной границы зоны, и не содержит неизмеренных обещаний экономии времени.

## На что опирается редизайн

- [Design for AI: Anti-slop principles](https://design.yaps.ai/docs/principles): ограниченная палитра, осмысленная композиция, анимация с понятной функцией.
- [Butterick’s Practical Typography: Presentations](https://practicaltypography.com/presentations.html): читаемость в условиях просмотра, согласованный размер текста.

Для этой версии выбраны светлый нейтральный фон для созвона, обычное начертание заголовков и кадры проекта вместо декоративных элементов. Анимация осталась в переходах и интерактивных состояниях. Настройка reduced motion учитывается.
